# Dataset

The repository includes a reproducible **synthetic demonstration dataset** in `data/sample/`:

- `synthetic_bike_demand.csv` contains hourly simulated training observations and the `count` target.
- `future_observations.csv` contains later simulated feature rows without a target, for the inference demonstration.

These records are generated by `scripts/generate_synthetic_data.py` using a fixed random seed. They are not real ride records, do not represent an actual operator, and must not be used to claim real-world demand accuracy.

## Generate the sample again

```powershell
python scripts/generate_synthetic_data.py
```

## Use a separate authorized dataset

The model also accepts a CSV at `data/raw/ola.csv` with these columns:

| Column | Description |
|---|---|
| `datetime` | Observation date and time |
| `season` | Season category |
| `weather` | Weather category |
| `temp (°C)` | Temperature |
| `humidity (%)` | Humidity |
| `windspeed (m/s)` | Wind speed |
| `count` | Total ride count (target) |

The optional `casual_riders` and `registered_riders` fields are excluded from model inputs because they can reveal the total target. Obtain external data from its original provider and confirm its licence, attribution and redistribution terms before use. Raw external data is excluded from Git by default.
